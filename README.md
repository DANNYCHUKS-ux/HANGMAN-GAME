# Hangman Game

## About the Project

Hangman is a simple, text-based Python game where the player tries to guess a hidden word one letter at a time. The game randomly selects a word from a predefined list, and the player has six incorrect guesses before the game ends.

## Features

- Random word selection
- Five predefined words
- One-letter-at-a-time guessing
- Six incorrect guesses allowed
- Input validation to prevent invalid entries
- Detection of previously guessed letters
- Win and lose conditions

## Technologies Used

- Python
- `random` module
- Loops and conditional statements
- Lists and strings
- User input and input validation

## How to Run the Game

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in your terminal or code editor.
4. Run the following command:

```bash
python hangman.py
```

## How to Play

1. Run the game.
2. Enter one letter when prompted.
3. Correct guesses reveal the matching letters in the hidden word.
4. Incorrect guesses reduce the number of attempts remaining.
5. Guess the entire word before using all six incorrect guesses to win.

## Learning Objectives

This project demonstrates the use of Python fundamentals, including loops, conditional statements, lists, strings, random selection, user input, and input validation.
